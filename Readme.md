# Monthly Expense Tracker

A beginner-friendly full-stack Python application for
recording expenses and analyzing daily, monthly, and
yearly spending.

## Technology Stack

- Python
- Streamlit
- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic

## Project Status

Phase 2: Project setup in progress.

## Planned Features

- Add, view, edit, and delete expenses
- Dashboard with spending summaries
- Daily, monthly, and yearly reports
- Search and filtering
- API and automated testing
